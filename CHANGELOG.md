## [Unreleased]

### Добавлено

- Публикация текстовых шагов и картинок: `stepik_plan_push` строит план и diff, ничего не отправляя, а `stepik_apply_push` публикует его после подтверждения автора. Можно менять существующие текстовые шаги и добавлять новые (метка `<!-- new_step -->`). Локальные картинки загружаются на Stepik как вложения урока.
- Защита записи: список курсов `ALLOWED_WRITE_COURSES` (по умолчанию пуст), проверка принадлежности урока курсу по API, отказ при изменении файла или урока на Stepik после плана, снимок урока в `snapshots/`, журнал `logs/stepik-write.log`, предупреждение о ссылках и оформлении, которые потеряются при публикации.
- Аннотации MCP: `stepik_apply_push` помечен как разрушающий, `stepik_plan_push` — как только читающий Stepik.
- 18 тестов публикации и Markdown → HTML. Публикация проверена на тестовом курсе 241862.
- Формат урока 2: задания хранятся как условие в Markdown и YAML-блок настроек (`steps.py`). Рядом с уроком сохраняются исходники шагов `.stepik/steps/<id>.json`; публикация сравнивает правку с ними и не затирает изменения, сделанные на Stepik после скачивания.
- `stepik_check_roundtrip`: проверка «скачать → собрать обратно» для всего курса. 683 из 683 шагов трёх курсов автора проходят.
- `ALLOWED_WRITE_COURSES=*`: запись в любой курс, где аккаунт токена автор или преподаватель.

- Публикация заданий: правки и новые шаги `choice`, `string`, `number`, `matching`, `sorting`, `free-answer` и `code`. Задание проверяется до отправки; шаги, которые уже решали ученики, требуют `confirm_steps` при применении.
- Локальный прогон эталонного решения задачи на код (`solution:` в YAML) на всех тестах перед публикацией.
- `stepik_rollback_lesson`: план возврата урока к снимку, применяется через `stepik_apply_push`. Удалённые шаги откат создаёт заново.
- Удаление шагов меткой `<!-- delete_step: N -->`: применение требует `confirm_delete` с точным списком шагов.
- Удаление комментариев: `stepik_plan_delete_comments` и `stepik_apply_delete_comments` с фильтром по тексту, автору и уроку, подтверждением точного числа и копией удалённого в `snapshots/`.
- `all_in_lesson` в `stepik_plan_delete_comments`: все комментарии одного урока, любых авторов, с ответами и комментариями без текста (только картинка). План показывает разбивку по авторам; ответы удаляются раньше корня ветки.

### Исправлено

- Снимки двух публикаций в одну секунду больше не конфликтуют по имени файла.

- Пункты списков с `<p>` внутри (так их сохраняет редактор Stepik) больше не превращаются в пустые `- `. Старые файлы уроков сравниваются прежним разбором, поэтому неизменённые шаги в них не попадают в план.
- Два блока кода подряд: у второго терялась открывающая ```, и в файле урока всё ниже считалось кодом, включая метки следующих шагов. Теперь каждый блок кода закрыт, разметка внутри `<pre>` не выводится, буквальные ``` в тексте экранируются. В старых файлах метки шагов ищутся без учёта оград.
- Шаг старого файла без исходника, который меняли на Stepik после скачивания (`update_date` позже `fetched_at`), больше не попадает в план: иначе публикация удалила бы правку, сделанную на Stepik.

## [0.2.0] — 2026-09-23

### Изменено

- Код разложен в устанавливаемый пакет `stepik_mcp` (`client`, `render`, `feedback`, `analytics`, `workspace`, `server`). Команды запуска: `stepik-mcp` и `python -m stepik_mcp`.
- Тесты перенесены в `tests/` и работают на любой ОС через системную временную папку (`STEPIK_MCP_TEST_TMPDIR` для переопределения).
- Документация перенесена в `docs/`: PRD обновлён до версии 0.2, `plan.md` разделён на [дорожную карту](docs/ROADMAP.md) и [заметки о проектировании](docs/design-notes.md).

### Добавлено

- `pyproject.toml`, CI на GitHub Actions (Windows и Linux, Python 3.12–3.13), линтер ruff.
- README с подключением к Claude Code, Claude Desktop и OpenCode; `AGENTS.md` и `CLAUDE.md` для агентов, работающих над репозиторием.

### Удалено

- Старый HTTP-мост `stepik_bridge.py` с токеном в URL. Режим `--http` MCP-сервера сохранён.
- Резервные копии `*_backup.py` и архив `stepik_mcp_opencode_bundle.zip`. Они остались в первом коммите истории.

### Миграция

Если клиент запускал `python stepik_mcp.py`, замените команду на `python -m stepik_mcp` после `pip install -e .`, или на путь к `stepik-mcp` в `.venv`.
