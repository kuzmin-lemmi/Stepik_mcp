# Локальная папка курса

Как Stepik MCP сохраняет курсы на диск, что гарантирует и как восстановиться после сбоя.

## Инструменты

| Инструмент | Что делает | Что возвращает |
| --- | --- | --- |
| `stepik_cache_lesson(course_id, lesson_position)` | Создаёт папку курса и папки всех модулей, сохраняет один опубликованный урок в Markdown | Путь и метаданные, **без текста урока** |
| `stepik_cache_lesson_comments(course_id, lesson_position)` | Сохраняет комментарии и ответы основного обсуждения рядом с уже сохранённым уроком | Путь и число комментариев |
| `stepik_cache_course_text_lessons(course_id)` | Сохраняет все уроки курса, но только шаги типа `text` | Сводку и пути |

К Stepik идут только GET-запросы (единственный POST получает OAuth-токен). Эти инструменты пишут только в локальную папку.

```text
stepik_cache_lesson(course_id=266999, lesson_position="5.2")
```

`lesson_position` берётся из полей позиции секции и unit Stepik (`модуль.урок`), а не из угаданной нумерации программы курса.

## Где лежат курсы

- Корень по умолчанию: `C:\Courses`. Переопределяется переменной окружения `COURSE_WORKSPACE_ROOT` (абсолютный путь). На Linux и macOS её нужно задать обязательно.
- Путь назначения нельзя передать в вызове инструмента: всё пишется только внутрь корня.
- Требуется Python 3.12+ и файловая система с жёсткими ссылками (NTFS, ext4, APFS).

## Структура

```text
<COURSE_WORKSPACE_ROOT>/course-266999/
├── .course.json
├── COURSE_MAP.md
├── AGENTS.md
├── 01-<название-модуля>-<section_id>/
├── ...
└── 05-<название-модуля>-<section_id>/
    ├── 05.02-lesson-2498212.md
    └── 05.02-lesson-2498212.comments.md
```

- Создаются папки всех модулей, но скачиваются только запрошенные уроки.
- Имя папки курса построено на ID; имя модуля безопасно для Windows и содержит ID секции.
- `.course.json` — снимок структуры: ID, пути и сведения об импорте.
- `COURSE_MAP.md` — генерируемый список уроков с отметкой, есть ли локальный файл.
- `AGENTS.md` — правила для агента: редактировать локальные файлы, аналитику запрашивать только по просьбе. Существующий `AGENTS.md` не перезаписывается.
- Комментарии хранятся отдельно в `.comments.md`: ID урока, шагов и комментариев, ответы, авторы и время загрузки. С текстом урока они не смешиваются.
- Урок начинается с YAML-frontmatter (значения в JSON-кавычках), дальше идут шаги с порядковыми заголовками и стабильными `step_id`. Ответы включены.

> Сейчас Markdown — это **редактируемое текстовое представление**, а не полная копия урока. Медиафайлы и все настройки выполнения задач не сохраняются. Формат без потерь — цель этапа 2 [дорожной карты](ROADMAP.md).

Чтобы агент прочитал `AGENTS.md`, откройте папку курса как проект в OpenCode или Claude Code. При работе из другого проекта клиент может запросить доступ к внешней папке; сервер не расширяет права сам.

## Сохранность и восстановление

- **Существующие уроки** возвращаются без чтения содержимого и без запросов к Stepik. Локальные правки никогда не перезаписываются. Название и число шагов в ответе взяты из данных импорта, а не из текущего файла.
- **Существующие `.comments.md`** тоже возвращаются без запросов и не перезаписываются. Принудительного обновления пока нет.
- **Отсутствующие файлы** можно скачать заново. Изменения на Stepik, переименование модулей и новые позиции **не синхронизируются** автоматически; неизвестная позиция даёт явную ошибку.
- **Новые черновики** можно создавать в папке модуля. Загрузчик не присваивает им ID Stepik и не добавляет их в карту.
- **Атомарная запись.** Урок публикуется в папку только после полной загрузки и рендера: временный файл сбрасывается на диск и появляется под целевым именем через жёсткую ссылку, которая не может заменить существующий файл.
- **Сбой API** может оставить корректную структуру и индекс, но не частичный урок. Повторный вызов завершает инициализацию и восстанавливает сгенерированные индексы.
- **Блокировка.** Папка `.stepik-cache.lock` защищает курс от одновременной записи. Если процесс упал, блокировка может остаться: убедитесь, что загрузчик не работает, и удалите её вручную. Не удаляйте `.course.json`, чтобы снять блокировку.
- **Повреждённый или отсутствующий `.course.json`** в заполненной папке курса — ошибка. Чужое содержимое не присваивается и не перезаписывается молча.
- **Защита путей.** Отклоняются выход за пределы папки (`..`), диски и альтернативные потоки Windows, а также символические ссылки и junction, ведущие наружу. Не подменяйте ссылки в файловой системе во время работы инструмента.

## Границы

Загрузчик урока не получает комментарии, статистику, решения и отзывы. Кэширование комментариев получает только обычные комментарии и ответы и только по явному вызову. Просьба скачать урок не требует от модели его читать; просьба проверить или отредактировать — требует.

## Проверка

```bash
python -m unittest discover -s tests -v
```

Тесты используют временные папки (системный temp или `STEPIK_MCP_TEST_TMPDIR`) и никогда не трогают настоящий корень курсов. Они покрывают выборочную загрузку, повторные вызовы без API, сохранность правок, неполные ответы API, сбои атомарной записи, восстановление, опасные пути и компактные ответы MCP.
